# Публичный справочник

Адрес `/help` доступен без авторизации, включая случай недоступного API или
устаревшего токена. Все сведения читаются из `public/help-data.json` с HTTP
перепроверкой кеша. Статьи и карты одинаковы на `adaliagame.ru` и
`test.adaliagame.ru`. Ссылки на разделы имеют вид `/help#сила`.

Источники — полное оглавление `https://vk.com/@adalia_game-help` (26 статей),
встроенное меню бота и действующие таблицы механик. Пояснения к терминам
доступны при наведении, фокусе с клавиатуры и касании; Escape закрывает подсказку.
Карты хранятся локально в `public/help-images`, чтобы ссылки ВК не устаревали.

## Обновление текстов и правил

В репозитории бота `docs/help/vk-articles.json` содержит перенесённые статьи,
`Data_sources/Information_data.py` — встроенную справку. Каталог заклинаний,
требования талантов, параметры травм и заветы экспортируются из таблиц игры.

После исправления источников из репозитория бота выполнить:

```sh
python3 scripts/export_game_help.py
python3 scripts/export_game_help.py --output /path/to/AdaliaApp/public/help-data.json
python3 -m unittest discover -s scripts -p test_game_help_export.py -v
```

Экспорт сверяет основу с `pythonProject1_mirror`, проверяет уникальность статей
и все внутренние переходы. Далее закоммитить JSON в этом репозитории и выполнить
обычный `bash deploy.sh test`, затем `bash deploy.sh production`.
Обновление справки не требует перезапуска API или бота. Изменённые ссылки
в ответах бота вступят в силу после его отдельного релиза.

При изменении механик обновлять дату `reviewedOn` в экспортёре и журнал сверки
`docs/help/help-audit.md` в репозитории бота. Не править одновременно старую
таблицу заклинаний из статьи ВК и новую: актуальный каталог строится из
`Data_sources/Magic.py`.
